description: "Start a brainstorming session — explore approaches before committing to implementation"
---

Activate `shifu:think-first` in G3 Phase B (Design) mode.

Your job: help the user explore ideas before writing any code.

1. Explore project context (files, docs, recent commits)
2. Ask clarifying questions — one at a time, prefer multiple choice
3. Propose 2-3 approaches with trade-offs and your recommendation
4. Present design incrementally, get user approval per section

**DO NOT** write code, create files, or start implementation. This is design only.

When the user approves the design, offer to continue with `/plan` to create an implementation plan.
