---
description: "Create a detailed implementation plan from a design or requirements"
---

Activate `shifu:think-first` in G3 full mode (Phases A-D).

Force G3 process regardless of apparent task size. This command means the user wants thorough planning.

1. If no design exists: run Phase A (Understand) and Phase B (Design) first
2. Phase C: Write spec document
3. Phase D: Write implementation plan with bite-sized tasks

Every step must include exact file paths, complete code, and test commands. NO placeholders.

When the plan is complete, offer execution choice: subagent-driven or inline.
